ざっくり暗記 -β版について

・このアプリは「ざっくり暗記 -β版」です。販売しているソフトではなく、データ保存まわりのテストがまだ十分ではありません。そのため、学習記録が消えてしまう可能性があります

・こちらではできる限りの対応をしますが、消えてしまった記録を保証することはできません。データが消える可能性を理解したうえでご利用ください。ご利用いただいた場合は、この内容に同意したものとみなします

・このアプリの学習記録は、あなたの端末（ブラウザ）の中にだけ保存されます。こちらでは保存していませんので、各自で管理してください

・ブラウザの「サイトデータをすべて削除」した場合も、記録は消えます。消えた記録はこちらでは復元できません

・バックアップは、手動でJSONデータをダウンロードして行います。自動でダウンロードはされません

・ダウンロードしたJSONデータを読み込めば、その時点の記録から始められます

間違えた項目が、間違えた日から7日以上たって再出題されたとき、正解できた割合です。途中でまた間違えた場合は、その日が新しい起点になります。

サンプル数が少ない間は、割合が大きくブレます。数がたまってから眺めるのがおすすめです。

卒業について

卒業した項目は、通常の出題から外れます。卒業の条件は2つです。①クイズで正解するたびに次回までの間隔が3日→7日→14日→30日→60日と空いていき、6回目の正解で卒業します（途中で間違えると段階は最初に戻ります）。②このリストで「もう知ってる」を押すと、その場で卒業になります。卒業したあとで「また出してほしい」と思ったら、その項目の「卒業を取り消す」を押してください。学習中に戻って、次の回から通常の復習として出題されます。

このアプリについて

「ざっくり暗記 -β版」は、販売しているソフトではなくβ版として公開しています。データ保存まわりのテストがまだ十分ではないため、学習記録が消えてしまう可能性があります。できる限りの対応はしますが、消えてしまった記録の保証はできません。ご利用は、その可能性を理解し同意したものとしてお願いします。

対象ブラウザ：Google Chrome 最新版（Android / iPhone / Windows / Mac）。記録は項目IDに紐づいているので、アプリが更新されても引き継がれます。バージョンアップの際も、「データ形式が変わったので最初からやり直し」にならないよう、記録を引き継げる形で慎重に対応します。デッキは英単語・日本史年表・世界史年表・世界史・用語・日本史・用語の5つで、記録はデッキごとに分かれています。

卒業の条件：クイズで正解するたびに次回までの間隔が3日→7日→14日→30日→60日と空いていき、6回目の正解で卒業します（途中で間違えると段階は最初に戻り、卒業していた場合も卒業は取り消されます）。リストで「もう知ってる」を押した項目も、その場で卒業になります。卒業した項目は通常の出題から外れますが、リストの「卒業を取り消す」でいつでも学習中に戻せます。戻した項目は通常の復習サイクルから再開します。
